# Volcanic Materials ID Lab (Honors Geology, course 342801)

Replaces the external profharwood.x10host.com lab used by "LAB Volcanic Materials Identification".

- `index.html`: the student lab site, published at https://claude.ai/artifact/KmmQFBXnyRKrP3og5uFHp7.
  It has 15 drawn specimens (VM-01 to VM-15), a hand-lens view, a cm grid, silica data, an ID guide, and a lab sheet.
- `quiz_key.json`: the dropdown options and answer key, one row per specimen.
- `build_quiz.py`: creates the matching Canvas New Quiz (15 fill-in-the-blank dropdown questions, 7 blanks each, 1 pt each).
  Created in course 342801 as quiz/assignment 13884035, unpublished, in Unit 1.4.

If you change a specimen in `index.html`, update `quiz_key.json` and the quiz to match.
